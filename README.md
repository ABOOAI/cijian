# 词间 · 英语学习中心

词间是一款面向初中英语学习的中文界面学习工具，围绕单词、句子和常用固定搭配，提供学习、听写、默写、纠错与间隔复习。当前应用版本为 **1.11.3**。

- 在线使用：[词间学习中心](https://abooai.github.io/cijian/)
- 项目仓库：[ABOOAI/cijian](https://github.com/ABOOAI/cijian)

## 主要功能

- **分类词库**：共711个内置词项，包含教材单元289词、小学词汇343词，以及数词、月份、星期79词。小学词汇在“预备单元”单独练习。
- **单词训练**：记忆与拼读、翻译辨义、听力辨义、听写和默写；任务中心按小组逐步练习。
- **句子学习**：句子本与句子听写按单元组织，共50句精选材料；每次练一句，提供中文提示、英文朗读和逐句批改。支持添加自定义句子。
- **固定搭配**：首批60条搭配，配有例句、易错点、结构专项和360道原创语境题；搭配进度独立记录。
- **语境应用**：搭配与语境、阅读理解、完形填空、句子讲解，提供批改和错因解释。前三类优先使用未见题目，有限题库耗尽时明确提示。
- **错题巩固**：听写、默写及搭配纠错按“看答案抄写→中文与语音回忆→仅听语音回忆”练三轮，逐轮答对后继续。字母对照区分错写、漏写、多写和词序问题。部分已核对词项提供音节分读，其余使用整词练习。
- **记忆追踪**：正常无提示答对，单词或搭配的总记忆强度增加10个百分点，上限100%；答错不扣强度。提示、抄写和纠错轮次不加分。达到100%退出自动复习，仍可手动练习。
- **自定义与检索**：支持自定义单词、句子和搭配；词典按需查询，资料不足时如实提示。
- **朗读与操作**：包含1,023个静态合成音频文件；支持回车提交与下一题、Ctrl重播、输入框自动聚焦，以及每日练习时长统计。

题库与教材材料均有明确的精选范围，不代表覆盖全部教材内容。合成语音不是自动口语评分系统。

## 学习记录与浏览器要求

无需登录。进度、自定义内容和练习时长保存在当前浏览器，不自动跨设备同步；清理站点数据可能导致记录丢失。

建议使用较新的桌面浏览器。首次播放可能需要点击朗读按钮。自定义内容的朗读依赖设备英语语音；本机自动翻译仅在支持相应浏览器API的环境可用。

## 安装与本地运行

建议使用 Node.js 22 LTS 或更新的受支持版本，以及 npm。克隆仓库后运行：

```bash
git clone https://github.com/ABOOAI/cijian.git
cd cijian
npm ci
npm start
```

浏览器打开 http://127.0.0.1:4173 。请通过HTTP服务器使用，不要直接以file://打开index.html。应用运行不需要付费API或服务端模型。

## 测试与构建

```bash
npm test
npm run build
```

npm test运行核心测试；npm run build校验资源并生成dist静态目录。jsdom仅用于开发测试，版本由package-lock.json锁定。

DOM测试（Bash）：

```bash
mkdir -p evidence
for file in tests/dom-*.mjs; do node "$file"; done
```

也可单独运行某个DOM测试。浏览器测试需另外提供可用Chromium；测试覆盖与历史限制见[TEST_REPORT.md](TEST_REPORT.md)。

## 项目结构

- src/：应用逻辑、词库、题库、音频清单
- audio/：静态MP3和音频许可说明
- dictionary/：词典分片和许可
- tests/：核心、DOM及浏览器测试
- backups/1.11.3/：完整备份包与校验清单
- build-static.mjs：资源校验与静态构建
- server.mjs：本地开发服务器

当前仓库已经包含展开后的完整文件，可直接开发，无需先解压备份。恢复说明见[BACKUP_RESTORE.md](BACKUP_RESTORE.md)，历史功能记录见[SOURCE_HISTORY.md](SOURCE_HISTORY.md)。

## GitHub Pages部署

当前网站从main分支根目录发布，.nojekyll使静态文件原样发布。提交到main后，GitHub执行Pages构建与部署；可在仓库Actions页面查看结果。

这是纯前端静态应用：学习逻辑在浏览器中运行，不提供通用后端服务。公开仓库适用GitHub Pages免费静态托管，实际使用仍受平台配额和规则限制。

## 数据与许可

音频和词典的来源、使用许可分别保留于[audio/LICENSE.txt](audio/LICENSE.txt)和[dictionary/LICENSE.txt](dictionary/LICENSE.txt)。引用材料的来源信息保留在对应数据中。请遵守各项适用许可，不将公开仓库等同于所有材料均可无限制使用。
